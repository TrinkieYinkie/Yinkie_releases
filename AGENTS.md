# Public Yinkie landing repository

This repository and every committed asset are public. Never include personal
information, local machine paths, private documents, credentials, account data
or internal application source. Use only reviewed public demonstration assets.

## Product facts
- Landing: https://yinkie.com
- Web application: https://yinkie.app
- Public support: support@yinkie.com
- The core application and main functionality on both Web and Desktop remain free.
- Future optional paid extras are allowed. Accounts, synchronization and other
  online services do not exist yet; never promise they cannot appear or must
  be free, and never imply a release date.
- Keep Desktop and Web capability differences explicit.
- A public release repository alone does not establish the app source license.

## Boundaries
Work only in this repository. Application source and WritersStudio reference
material are read-only and must never enter this repository. Preserve existing
user edits. Use the primary worktree and task branches; do not merge main, push
or publish without an explicit user request. Do not create or edit workflow files.

## Local development
The landing is plain HTML, CSS and JavaScript, with no install required.
Use the bounded lifecycle entry points documented in docs/landing.md.
Keep all visible copy synchronized in English, Russian and Spanish.
Use shared theme tokens for controls, focus, scrollbars and both color schemes.
Do not synthesize new application screenshots or mislabel existing captures.
