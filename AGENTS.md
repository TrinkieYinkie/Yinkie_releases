# Public Yinkie landing repository

This repository and every committed asset are public. Never include personal
information, local machine paths, private documents, credentials, account data
or internal application source. Use only reviewed public demonstration assets.

## Product facts
- Landing: https://yinkie.com
- Web application: https://yinkie.app
- Public support: support@yinkie.com
- Beta participants will be able to leave an email address and receive an
  activation code for selected additional features at no charge. Do not advertise
  the whole current application or all future Desktop features as free.
- After beta, a base edition and paid activation keys for additional features
  are planned. Prices belong in Pricing once payments are connected; do not invent
  prices, workspace limits, key duration or already-working enrollment.
- The maintainer may change features available without payment in each update,
  subject to applicable law and existing paid-license rights.
- Accounts, synchronization and other online services are not currently available;
  do not promise their availability, price or delivery date.
- Keep Desktop and Web capability differences explicit.
- A public release repository alone does not establish the app source license.

## Boundaries
Work only in this repository. Application source and WritersStudio reference
material are read-only and must never enter this repository. Preserve existing
user edits. Use the primary worktree and task branches; do not merge main, push
or publish without an explicit user request. Do not create or edit workflow files.

## Local development
The landing is plain HTML, CSS and JavaScript, with no install required.
Use the bounded lifecycle entry points documented in docs/landing.md.
Keep all visible copy synchronized in English, Russian and Spanish.
Use shared theme tokens for controls, focus, scrollbars and both color schemes.
Do not synthesize new application screenshots or mislabel existing captures.

## Markdown compatibility positioning
The current profiles are Yinkie Markdown 5.0, CommonMark 0.31.2, GFM 0.29,
and GitHub repository Markdown reviewed 2026-08-27. Present selection as a
compatibility target with diagnostics, not automatic format conversion or a
guarantee for arbitrary editors/plugins. The GitHub profile covers repository
.md files. Existing target selection and new-file defaults are both supported.
