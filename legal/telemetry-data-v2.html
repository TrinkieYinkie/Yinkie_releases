Yinkie analytics data inventory

Contract version 1 · Privacy Policy version 2 · 19 October 2026

Analytics is optional and requires explicit consent. This inventory describes every permitted event; no document contents, filenames or paths are included.

This is the complete event-name and event-property inventory. All fields are closed allowlists: an unknown field, value, version or target combination is rejected before storage.

Fields on every event

eventId, eventName, eventVersion, random installationId, random sessionId, application version, target, distribution, coarse platformFamily, interface locale, UTC occurrence time and the exact property object listed below. These random identifiers are pseudonymous and can associate events from the same installation. They are not guaranteed anonymous.

The authenticated batch contains exactly schemaVersion: 1, contractVersion: 1, deletionSecret and events. Contract version belongs to the batch, not individual wire events. The separate deletion request contains only installationId and deletionSecret. The secret is not an event property or renderer-visible value. Server-side HMAC fingerprints protect credential checks; event identifiers remain stored with events.

Closed dimensions

  • target: desktop, web;
  • distribution: desktop-direct, web-free;
  • platform family: windows, macos, linux, browser;
  • interface locale: en, ru, es;
  • durations and counts: fixed coarse buckets only;
  • outcomes, errors, features and operation sources: fixed enumerations only.

Never collected by analytics

Document or Markdown content; document, file, folder, workspace, project, recovery or asset names and paths; search or replacement text; clipboard content; image bytes or URLs; headings, links or diagram source; internal resource identifiers or stable hashes; account, email or payment data; IP address or user agent; cookie or advertising identifier; precise OS or browser version; screen, font or device fingerprint; error message, stack, cause or arbitrary metadata.

Retention and deletion

The local queue holds at most 500 events for 30 days. The service is configured for 90 days of raw events and a 120-day maximum for deletion records. Encrypted backups have a target retention of 30 days, but backup transfer and restoration are not yet verified. Successful authenticated deletion removes active raw rows; later live metric queries stop including that installation. It does not erase every backup immediately. See the Privacy Policy for the periodic-copy restore risk, offline deletion and network information. Contact support@yinkie.com for questions.
